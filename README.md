У репозиторії є всі класи/інтерфейси згідно заданої специфікації, включаючи структуру пакетів. Для збірки використано Gradle

`src/main` - Імплементація завдання

`src/test` - Юніт тести, покривають код
## Build/Test
`./gradlew test` - Виконати тестування. Тести налаштовані виводити у стандартний потік результати тестів

`./gradlew javadoc` - Генерація документації в стилі javadoc(`build/docs/javadoc`)
